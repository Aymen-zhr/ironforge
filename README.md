# ironforge

Elite AI Gym App built with **React Native (Expo SDK 52+)**, **NativeWind v4 (Tailwind CSS)**, and **React Native Reanimated**.

## Overview
IronForge delivers high-performance hypertrophy telemetry, computer vision physique analysis, and real-time fridge macro synthesis.

- **Obsidian / Emerald Aesthetic**: Deep black background (`#090A0F`), glowing emerald accent (`#10B981`), and neon-cyan telemetry indicators (`#06B6D4`).
- **Graphify Knowledge Graph**: AST ontology mapping entity relationships with zero context rot (`graphify.json`).
- **Tactile Design System**: `GlassCard`, `GlowButton` (with Reanimated spring physics), and `MetricBadge` (S/A/B/C tiering & macro telemetry).

## Tech Stack
- **Framework**: Expo / React Native (TypeScript)
- **Styling**: NativeWind v4 (Tailwind CSS)
- **Animation**: React Native Reanimated
- **Icons**: Lucide React Native
- **Architecture**: Graphify Knowledge Graph & Antigravity Directives

## Quick Start
```bash
# Install dependencies
npm install

# Start development server
npx expo start -c
```
